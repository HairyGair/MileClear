# SEO title and description changes, October 2026

Shipped: 2 Oct 2026 (branch commit, not yet deployed). Measure CTR in Google Search Console 3 to 4 weeks after deploy, comparing the 28 days after deploy with the 28 days before (baseline figures below are the 28 days to 2 Oct 2026).

Why: several queries showed MileClear in the top 3 with no clicks, which usually means the snippet does not match what people typed. Titles now front-load the searched words, carry a concrete hook (free, iPhone and Android, automatic, 55p a mile from April 2026) and end with the brand. Descriptions are 140 to 158 characters.

Titles below are as rendered in the page `<title>` (the root layout adds " | MileClear" to plain string titles). Not touched here (other agents own them): /hmrc-mileage-rates, /best-mileage-tracker-app-uk, /employee-mileage-tracker, /what-counts-as-business-mileage, /dpd-mileage-tracker, /android.
